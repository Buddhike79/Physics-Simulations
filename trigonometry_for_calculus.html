Why are sine and cosine connected?

The unit circle and Pythagoras force a relationship between them.

Unit circle: x² + y² = 1
P = (cos θ, sin θ)
(cos θ)² = 0.500 (sin θ)² = 0.500
(cos θ)² + (sin θ)² = 1.000
sin²θ + cos²θ = 1
03 / MOTION

Change the motion. Watch the wave change.

Radius changes amplitude. Speed changes frequency. Starting angle changes phase.

RADIUS+SPEED+PHASE→NEW WAVE
Radius changes the amplitude:   y = R sin θ
Rotation speed changes the frequency:   y = R sin(kθ + φ)
